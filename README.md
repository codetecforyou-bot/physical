# Physical Center — Landing page

Site estático (HTML + imagens), sem build.

## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub (os arquivos `index.html`, `vercel.json` e a pasta `img/` na raiz).
2. Na Vercel: **Add New → Project → Import** o repositório.
3. Framework Preset: **Other**. Build Command e Output Directory: deixe em branco.
4. Clique em **Deploy**.

Para atualizar o site, basta substituir os arquivos no GitHub — a Vercel publica sozinha.
